# Neuro Spike Classifier

This project implements a binary classification model for neural spike train data to distinguish between familiar and novel stimuli.  
It compares Logistic Regression and Random Forest using scikit-learn.

## Files
- `neuro_spike_classifier.ipynb`: Jupyter Notebook with full code and explanation
- `slides.pdf`: Summary slides for presentation
- `requirements.txt`: Required packages to run the notebook
